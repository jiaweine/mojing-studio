# 墨境 · 验证记录

这份文档只记录当前交付目录实际重新执行过的检查，不沿用旧发布数字。测试可以显著降低已知缺陷，但不能数学意义证明软件永远没有 bug。

## 自动回归

执行：

```bash
make check
```

同时也直接执行过：

```bash
pytest -q
```

当前结果：

```text
Python compile          PASS
Frontend JS syntax      PASS
pytest                   46 passed
```

当前自动测试覆盖：

- 风险驱动任务规划与专业检查选择；
- 多方案章节设计与结构硬门；
- 工具调用预算与重复查询复用；
- 多 provider 分工和失败回退；
- OpenAI 最高创作深度会原样发送 `reasoning_effort=max`，不再被旧兼容逻辑降级；
- DeepSeek thinking + tools 不发送冲突的 `tool_choice`；
- Claude 并行工具结果保持同一 user turn，并保留原生 thinking 块；
- Gemini 并行函数结果保留原始调用 ID 与原生 thought signature；
- 质量维度重新计算与硬连续性冲突兜底；
- 章节原子提交；
- 浏览器流断开后后台继续完成；
- 已保存结果不会被最后一次回包错误改成失败；
- 同一本书多进程/多标签页写作租约；
- 同一个失败任务恢复时可续租；
- 写作锁采用短租约 + 运行事件自动续租；进程异常退出后不会长时间卡住作品；
- `ready_to_commit` 检查点可以直接恢复提交、不重新生成；
- 运行中作者补充要求持久化、消费与不支持任务的明确拒绝；
- 无效 JSON、损坏图片、超大像素图和上传落盘失败清理；
- 客户页面不存在后台专有词；
- 页面本地 CSS / JS / 三张示例视觉素材都存在。

## 页面设计审查

当前视觉按“出版社编辑台 × 长篇写作工具”处理：

- 深墨书架、冷白纸张、单一朱红强调；
- 阅读文字明显大于附属信息；
- 正文/章节使用更具编辑气质的衬线字体栈；
- 快捷操作不做四张等宽 SaaS 卡；
- 右侧资料依靠排版和分隔线而不是卡片墙；
- 不使用紫蓝科技渐变；
- 不使用 Inter 作为万能默认字体；
- 无循环发光/脉冲动画；
- `prefers-reduced-motion` 有降级；
- 手机采用专注正文 + 可切换资料层，而不是压缩三栏。
